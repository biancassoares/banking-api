# Banking API 🏦

API REST bancária simplificada, desenvolvida com **Java e Spring Boot**, com foco em desenvolvimento backend, regras de negócio e operações financeiras.

> 🚧 **Este projeto ainda está em desenvolvimento.**
> Novas funcionalidades, melhorias e uma documentação mais completa serão adicionadas em breve.

## Funcionalidades implementadas

* Cadastro de clientes
* Criação de contas bancárias
* Depósitos
* Saques
* Transferências entre contas
* Extrato de transações com filtros e paginação
* Validações de regras de negócio
* Tratamento de exceções customizadas
* Idempotência em operações financeiras
* Testes unitários

## Tecnologias utilizadas

* Java
* Spring Boot
* Spring Data JPA
* PostgreSQL
* Docker
* Maven
* JUnit
* Mockito

## Em desenvolvimento

* Spring Security
* Autenticação com JWT
* Melhorias finais
* Documentação completa do projeto
